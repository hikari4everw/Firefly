# 追番页设计

本机编辑、静态发布。季度导入 Bangumi 首播动画后自行筛选；支持条目链接补录。
版本默认名称为追番计划、中期评价、完结评价。计划档位：必追、想追、观望；评价档位：神作、佳作、还行、及格、差。
封面可在档内或相邻档位分界处；分界封面上下各占一半，不新增档位。普通封面换行；边界封面保持单行，窄屏局部横向滚动。
草稿存本机忽略目录，显式保存公开快照；旧快照不可覆盖，可复制成草稿。计划转评价保留清单、全部回待评价区。
公开页面默认最新季度及最新版本；历史固定链接；关联博客以独立映射保存，文章草稿不在生产展示。
界面沿用 MainGridLayout、主题变量、卡片及深浅色模式；生产无编辑器和写入接口，不含本机草稿。
