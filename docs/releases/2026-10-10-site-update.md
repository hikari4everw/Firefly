# 2026-10-10 网站更新

## 访客外观设置

- 正式网站开放外观、壁纸、特效三个标签，仍遵循配置与环境变量总开关。
- 调整仅保存到访客自己的浏览器，刷新和站内跳转后保留，不修改站点默认值。
- 恢复站点默认仅移除个人外观偏好，保留亮暗色及其他功能的数据。
- 页面调试、保存为站点默认、恢复出厂设置仍只在本地开发可用；正式网站没有写入接口。
- 首次访问使用发布的默认样式，壁纸、标题、轮播和特效支持访客开关，并保留设备默认差异。

## 全站布局与文章卡片

- 基础字号统一为 16px，桌面共享容器为 94vw，最大宽度 96rem；导航、内容和页脚对齐。
- 桌面侧栏宽度 17.5rem，列间距 1rem；无侧栏内容比例 0.72，正文最大阅读宽度 54rem。
- 桌面文章标题为 20px / 28px，摘要为 14px / 1.6，文字上下内边距 20px、外侧 24px。
- 手机保留单列及底部组件；追番页使用单侧栏，站内跳转后恢复其他页面布局。
- 整张文章卡片使用原生链接，支持普通点击、Command / Ctrl 点击、中键和右键；分类、标签独立跳转。
- 网格标题在内层截断，避免影响整卡点击区域；手机缩放元数据仍可单独点击。
- 增强卡片边线与阴影；悬停、键盘焦点显示主题色标题和阅读箭头，整卡不移动或缩放。
- 关闭卡片边框与阴影后仍保留标题、箭头和手形指针反馈。

## 追番页面

- 新增 `/anime/` 季度追番排行及固定历史版本页面。
- 本地可导入当季日本 TV 动画、筛选排序、保存草稿和生成公开快照；正式网站仅展示公开结果。
- 草稿位于忽略目录 `.local/anime/`，公开版本位于 `src/data/anime.json`。
- 本次公开数据为空，正式页显示准备中的空状态；后续发布公开快照后随代码部署更新。
- 具体操作见 [追番排行说明](../anime-ranking.md)。

## 字体与音乐

- 启用 Lolita Second Edition 本地字体，并沿用构建时字体子集处理。
- 歌单及封面改用现有 ImageKit CDN，新增 Believe Me，移除被 CDN 替代的本地音乐文件。

## 发布核验

- 运行现有回归与外观验证脚本、`pnpm check`、`pnpm type-check` 和完整构建。
- 检查首页、文章、归档、关于、追番页面在 390 / 900 / 1440 / 1920px 下的布局与横向溢出。
- 检查列表与网格、左右封面、无封面、分类标签、分页、站内跳转及键盘、新标签页操作。
- 检查亮色、暗色、透明壁纸及关闭边框时的卡片反馈。
