# 页面调试工具验证记录

验证日期：2026-10-05。本次完成代码与本地验证，没有部署。

## 使用方式

运行 `pnpm dev`，打开导航栏外观面板，选择「页面调试」。板块标题行提供隐藏、保存此板块及状态，展开后可编辑样式和常用内容。输入立即预览，刷新及 Swup 换页继续使用当前浏览器的草稿。

只有勾选的板块会通过「保存所选板块」写入 `src/constants/saved-ui-visibility.json`，未选板块继续留在本地预览。单板块和全局恢复均先清理本地预览；勾选并保存对应板块后才删除磁盘覆盖。保存后必须重新构建部署才能让访客应用。

生产页面只使用保存配置。调试入口、面板和写入接口仅在本机开发服务器存在，原配置未启用的功能不会因覆盖而创建。

## 交互与持久化

- 桌面 1280×720、手机 390×844：RSS 点击往返、Logo 返回、导航返回、浏览器后退。页面过渡完成后四个链接中心命中对应链接；RSS 可使用 Enter 打开。首页全屏 Hero 壁纸保持内联 `z-index: 10 !important`。
- 标题文字、字号、字重、行高、颜色即时预览；超出范围的字号拒绝应用，并保留输入供修正。
- 副标题列表更新后，打字机使用新内容；刷新及 RSS 软导航保留列表。
- 首页链接名称、已安装图标集中的图标及尺寸即时更新。清空图标后再设置有效图标，默认 class/style 被保留。外链、站内链接、锚点及原邮箱编码机制继续使用；测试覆盖协议大小写。
- 修改导航父菜单名称和图标尺寸，桌面及手机节点同步更新，手机父菜单 SVG 实际尺寸为 32px。
- 公告标题、正文、显示标题及卡片背景透明度即时更新。背景实际渲染值为 `color(srgb 0.2 0.4 0.6 / 0.4)`，标题隐藏后正确补齐内容上边距。
- 全部左侧模块隐藏后，原三列变为内容和右栏两列，隐藏卡片均无可见矩形；恢复后布局恢复。保留第一阶段已验证的固定目标清单、禁用功能不启用、隐藏元素不可获得键盘焦点机制。
- 同时修改主标题、GitHub 链接、页脚说明，仅选择前两个保存：磁盘仅含前两个覆盖；页脚保持本地草稿，刷新及跨页继续预览。
- 人为用同名临时目录使原子写失败：界面显示 EISDIR 原因，草稿和两个保存选择均保留；移除测试目录后重试成功。
- 恢复原配置后选择已保存的两个板块保存，删除对应覆盖；其余未选板块不写入文件。

- 单元测试覆盖旧隐藏配置兼容、按板块合并、未选磁盘值保留、删除覆盖、非法目标/字段/数值/地址/图标拒绝、精确 CSS 目标与链接行为。
